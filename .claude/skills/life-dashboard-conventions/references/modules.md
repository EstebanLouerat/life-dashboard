# Modules — scope and status

Update the **Status** line of a module when you change it.

## Navigation
Five tabs, each a stack: Accueil (the Aujourd'hui screen, src/app/(tabs)/(aujourdhui)/, URL "/"), Courses, Sport, Santé, Plus (Wishlist, Abonnements, Importer, Backlog, Réglages in src/app/(tabs)/plus/). The floating glass tab bar (components/TabBar.tsx) shrinks to a round button while scrolling down, and carries the undo snackbar and the session accessory. New modules go in their domain's tab or under Plus with a row in its list, never a new tab. The root is a Stack: full-screen flows that must hide the tab bar (src/app/seance/, src/app/hair-check/, src/app/capture.tsx) are pushed over the tabs from the bottom.
Design reference: the "Life Dashboard — Écrans Android" canvas (Carnet calme × Liquid Glass). Not built from it: Android 16 Live Updates as such (the ongoing session notification asks for promotion on Android 16, see Workout), iOS Dynamic Island (Android-only app), the generic "Ajouter un suivi" model, the Appart row in Plus, a real backdrop blur (glass is a translucent fill + highlight, no expo-blur).

Edit in place (long press on a tile, the pencil or the calendar icon's menu): hold and drag a tile onto another's place, remove (with undo), stretch / shrink, add a tile; Personnaliser (list with drag handles and screen-reader moves) from the edit bar. Calendar icon menu: +1 verre, modifier, idée, bug, Réglages. Summary line "Reste : …". Capture "Idée / bug" from the header. Home-screen widgets (EAS build only, src/widgets/): Eau (1×1 tap = a glass, 2×1 + / undo, larger: gauge, +1 / +2 glasses, undo), Traitements (today's doses to tick, 1 row: next dose button), Sommeil (4 range chips, taller: 7-night bars), Courses (checklist by aisle + tonight's dinner; small: count), Séance (see Workout). ## Groceries (src/app/(tabs)/courses/, /api/groceries)
Scope: weekly meal plan → shopping list sorted by aisle, budget (default 60 €), days, people, store (Lidl/Auchan). Prices: user-maintained table (`knownPrices`) beats Claude estimates; later fed by receipt OCR and Open Prices.
Status: generation (dinners only, from the header), import from pasted JSON (Plus › Importer, keeps ticks of items still listed), storage with the plan's start day, parameters card + sheet (settings courses_*), estimated total vs budget with known / estimated price chips, menu carousel with recipe steps, list in walking order with check-off, error banner with retry. Missing: pantry inventory, price table UI, receipt scan, "new plan received" banner (needs plans pushed by the server). Gestures: swipe an item right to tick / untick; long press: tick or untick the whole aisle, copy the item; cart icon menu: generate, import, copy what is left (by aisle), untick all (with undo).

## Workout (src/app/(tabs)/sport/, src/app/seance/, components/WorkoutRunner.tsx, lib/workoutTimeline.ts, /api/workout)
Scope: daily short session (default 10 min), zero equipment, capoeira mobility (hips, adductors, hamstrings, thoracic spine, wrists/shoulders) + very progressive bodyweight strength. Progression driven by RPE feedback of the last 7 sessions.
Status: generation (sheet), import from JSON, session by block, guided full-screen timer (sets and rests, auto-advance, reps wait for "Série faite", pause / previous / next), session accessory above the tab bar while it runs, feedback screen (RPE + note), history of the last 7. Ongoing session (EAS build only, modules/live-session): foreground-service notification with a countdown, Pause / Suivant (Série faite) / Arrêter, tinted sport colour (colorized below Android 16, promotion requested on 16+); optional floating capsule over other apps (Réglages › Séance en cours › Capsule flottante, "Afficher par-dessus" permission), draggable, tap opens the timer, button pauses. Widget Séance: exercise, set, end time or pause, previous / pause or Série faite / next / stop; idle: Commencer (lifedashboard:///seance?start=<id>), finished: Noter. Missing: streak with rest days, keep-awake during the timer, Samsung Now Bar / status chip (One UI allowlist only). Gestures: Historique rows swipe right = redo today (copy as today's session), swipe left = delete (with undo), long press = both; pulse icon menu: resume, generate, import, history.

## Health (src/app/(tabs)/sante/, src/app/hair-check/, lib/stock.ts, lib/adherence.ts, lib/treatments.ts, lib/hairPhotos.ts, lib/hairChecks.ts)

Santé replaces the Hair care module: Suivi (Cheveux photo series, Sommeil) and Traitements (renewal banner with one-tap "Renouvelé" + undo, compact cards with status and stock, detail = full TreatmentCard, edit form). Cheveux: monthly series, per-zone timeline, compare. Missing: the generic "suivi" model (photos / value / duration / check) and its "Ajouter un suivi".

Status: phase 1 done — configurable treatments (versioned regimens), one-tap check-off with explicit "missed" + notes, 30-day history with late catch-up, stock from logged events (pool, add/replace box, waste margin), run-out estimate (14-day real average, planned rate fallback), adherence 7/30 d, renewal + prescription reminders (stable ids, recomputed on each check-off) with Today banners as fallback. Gestures: Traitements cards swipe right = Pris (next open dose), swipe left = Sauté, long press = Pris / Sauté / box renewed / edit / history; icon menu: add a treatment, photo check, hair follow-up, reminders.
Phase 2 done (works in Expo Go) — monthly photo check in tables hair_checks / hair_photos: checklist, guided camera per zone (front camera for hairline and temples, back camera + 10 s countdown for vertex and top), frame, bubble level (DeviceMotion), last photo of the zone as a 40 % ghost, brightness check against the zone's first photo (mean luma of a 64 px copy decoded with jpeg-js, plus EXIF exposure; retake offered past 15 % or 1 EV), notes and side effects, timeline per zone and before/after slider. Photos and thumbnails live in the private document directory (hair/), android.allowBackup is off (effective in EAS builds only). Monthly reminder `hair-check` on the due day + Today banner. To check on a device: level direction, ghost alignment with the front camera mirror, EXIF keys returned by the phone. Later: automatic alignment score, PDF export for the dermatologist.
